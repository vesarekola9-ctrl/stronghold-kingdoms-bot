# Windows 11 -porttaus

Alkuperäinen Android/ADB-botti säilyy ennallaan. Tämä on natiivin Windows-version ensimmäinen testattava vaihe.

## Käynnistys
Avaa Stronghold Kingdoms Windowsissa. Kaksoisklikkaa `KAYNNISTA_WINDOWS11.bat`. Python 3 ja internetyhteys tarvitaan ensimmäisellä käynnistyksellä.

## Toteutettu
- Windowsin natiivin ruutukaappauksen tallennus
- Yhden klikkauksen käynnistin ja riippuvuudet
- Ei Androidia, BlueStacksia tai ADB:tä

## Kesken
- Pelin ikkunan paikannus
- Honor-alueen kalibrointi
- Resurssipussukoiden tunnistus käyttäjän kuvamalleista
- Scout/Go-toimintojen tunnistus ja yhden scoutin lähetys
- Opetus käyttäjän esimerkkitoimista
- Windows-EXE-julkaisu

**Ei vielä automaattinen scouttaaja.**
